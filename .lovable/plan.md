# Evitar produto duplicado no cadastro rápido

## Alteração
- Antes de criar um componente pelo cadastro rápido do kit, procurar um produto com o mesmo nome na empresa.
- Se houver correspondência, pedir confirmação para criar outro produto separado.
- Cancelar a operação quando a confirmação for recusada; manter o fluxo atual quando aceita.
